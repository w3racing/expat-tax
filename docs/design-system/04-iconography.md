# Iconography

## Library

**Lucide React** — consistent 24px grid, elegant strokes, matches Linear/Notion calm.

## Sizes

| Token | Px | Stroke | Use |
|-------|-----|--------|-----|
| `icon-xs` | 14 | 2 | Inline with caption |
| `icon-sm` | 16 | 2 | Buttons, chips |
| `icon-md` | 20 | 2 | Nav items, list leading |
| `icon-lg` | 24 | 1.75 | Empty states, FAB glyph |
| `icon-xl` | 32 | 1.75 | Feature illustrations (icon-led) |

Default: `icon-md` / stroke 2.

## Colour

- Inherit from parent text colour
- Active nav / primary actions: `primary`
- Decorative on soft fills: `Ink 700` or `Cerulean 700`

## Rules

- No emoji in product chrome
- Icon-only controls require visible or SR label
- Prefer outline Lucide icons; avoid filled except for selected nav affordance
- Pair status icons with text labels
