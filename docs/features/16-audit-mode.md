# Audit Mode

## Purpose

Flagship feature: generate a **complete ATO-ready audit package** from organised evidence — for a tax agent or the ATO.

## Claim traffic lights

| Colour | Label |
|--------|-------|
| Green | Evidence Complete |
| Yellow | Evidence Mostly Complete |
| Red | Missing Evidence |

Clicking a claim immediately shows every linked document.

## Package includes

Income · Payslips · PAYG · Travel · Rosters · Flights · Receipts · ATO FX Calculations · Investments · Rental Property · Supporting Documents · Evidence Index · Tax Calculations · Notes

## Generates

- PDF summary
- ZIP archive (deterministic section folders)
- Evidence index (CSV + PDF)
- Chronological timeline (PDF + JSON in ZIP)

## Options

- Include historical versions
- Include accountant notes
- Include indicative tax calculation working papers

## Acceptance

- Suitable for tax agent or ATO information request handoff
- Cover page states AJX organises evidence; indicative figures are not lodgement
- Empty sections explicitly listed
- Traffic lights accurate per ruleset version
- Claim click → full linked document list without navigation maze
- Package mirrors to Drive `Audit Package/` when connected
