# Onboarding

## Purpose

Collect the minimum profile to personalise capture and categories — without feeling like tax software setup.

## Steps (short)

1. Welcome + philosophy (“Capture once…”)
2. Occupation segment (pilot, cabin crew, FIFO, consultant, traveller, other)
3. Home base timezone / state (for FY boundaries)
4. Optional: connect Google Drive
5. First capture CTA

## Rules

- Skippable Drive connect
- Completing sets `onboarding_completed_at`
- Revisitable from Settings

## Acceptance

- ≤ 60 seconds for typical path
- Feels premium; no form-heavy ATO vibe
