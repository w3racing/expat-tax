# Settings

## Purpose

Profile, FY preferences, integrations, data export/delete, appearance.

## Sections

- Profile (name, segment, timezone)
- Financial year defaults
- Google connection
- **Accountant Mode** — invite, permissions, audit trail, revoke
- **Audit Mode** — flagship ATO package; claim traffic lights; PDF + ZIP + index + timeline; optional historical versions
- Notifications (v1: minimal / none until email exists)
- Privacy: export data, delete account
- Shortcuts help (desktop)

## Acceptance

- Delete account removes DB rows and Blob objects (documented retention window if any)
- Audit Mode generates complete package suitable for tax agent or ATO handoff
- Audit Mode export can optionally include full version history
- Accountant invite, revoke, and permission changes work end-to-end and are audited
